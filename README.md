# Playground 

My sandbox for breaking things, fixing them, and calling it learning.

## What's in here

Small Go programs and practice solutions, written while learning the language.
Each folder is a self-contained exercise.

## Running things

Make sure you have [Go](https://go.dev/dl/) installed, then:

    cd some-exercise
    go run .


## Why this exists

Because the best way to learn to code is to write a lot of it, get it wrong, and slowly get it less wrong.
